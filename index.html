GIỚI THIỆUINTRODUCTION #

Dịch vụ thanh toán Redirect link của Pay2Pay là giải pháp thanh toán toàn diện, giúp doanh nghiệp dễ dàng thu tiền trực tuyến trên website. Thay vì phải làm việc rời rạc với từng ngân hàng hay ví điện tử, bạn chỉ cần tích hợp duy nhất 1 API. Pay2Pay's Redirect Link Payment Service is a comprehensive payment solution that makes it simple for businesses to collect online payments on websites. Instead of working separately with each bank or e-wallet, you only need to integrate a single API.

Tại bước thanh toán, hệ thống sẽ chuyển hướng (redirect) khách hàng đến cổng thanh toán an toàn của Pay2Pay. At the checkout step, the system redirects the customer to Pay2Pay's secure payment gateway. Customers can choose their preferred payment method: Domestic ATM card, International card (Visa/Mastercard/JCB), Bank Transfer, QR Pay, and Installments.

II. MÔ HÌNH TRUYỀN THÔNGII. COMMUNICATION MODEL

  • Pay2Pay sử dụng tiêu chuẩn kết nối HTTPS/TLS1.2. Pay2Pay uses HTTPS/TLS1.2 connection standard.
  • Mọi yêu cầu được gửi từ phía người bán đều phải được xác thực bằng giải pháp JSON Web Token. All requests sent from the merchant must be authenticated using JSON Web Token.
  • Pay2Pay cung cấp API theo tiêu chuẩn Restful Webservice, truyền và nhận dữ liệu ở định dạng JSON. Pay2Pay provides APIs according to the Restful Webservice standard, transmitting and receiving data in JSON format.
  • Để đảm bảo việc truyền và nhận dữ liệu giữa hai bên được an toàn và xác thực, tất cả dữ liệu sẽ được mã hóa và ký điện tử. To ensure that data transmission and reception between the two parties are secure and authenticated, all data will be encrypted and digitally signed.

III. QUY TRÌNH THANH TOÁN VÀ XÁC THỰC MÃ III. PAYMENT PROCESS & AUTHENTICATION

Tất cả các yêu cầu từ người bán gửi đến hệ thống Pay2Pay đều cần được ủy quyền để đảm bảo an ninh. Dưới đây là luồng xử lý giao dịch cơ bản. All requests from the merchant to the Pay2Pay system must be authorized to ensure security. Below is the basic transaction flow.

III.2. CHỮ KÝ ĐIỆN TỬ (RSA-2048) III.2. DIGITAL SIGNATURE (RSA-2048)

  • Người bán tạo cặp khóa RSA-2048 (khóa riêng tư và khóa công khai). The merchant creates an RSA-2048 key pair (private key and public key).
  • Khóa riêng tư dành cho người bán để tạo chữ ký. Khóa công khai gửi cho Pay2Pay để xác minh. The private key is for the merchant to create a signature. The public key is sent to Pay2Pay for verification.
  • Cách tạo chữ ký:
    Bước 1: Lọc và sắp xếp các tham số header (bắt đầu bằng p-) theo bảng chữ cái và nối lại.
    Bước 2: Kết hợp với phần thân (body) yêu cầu.
    Bước 3: Chữ ký = SHA256withRSA(Chuỗi cần ký ở Bước 2)     How to create a signature:
    Step 1: Filter and sort header parameters (starting with p-) alphabetically and concatenate them.
    Step 2: Combine with the request body.
    Step 3: Signature = SHA256withRSA(String to sign from Step 2)

    VIII. CODE SAMPLE

    1. PHP

    function computeSha256HashBase64( $inputString ) {
    // Tính toán mã băm SHA-256 của chuỗi đầu vào
    $hash = hash( 'sha256', $inputString, true );
    // Mã hóa giá trị băm thu được dưới dạng Base64
    $base64Hash = base64_encode( $hash );
    return $base64Hash;
}

    2. C#

    public static string ComputeSha256HashBase64(string inputString) {
    byte[] inputBytes = Encoding.UTF8.GetBytes(inputString);
    using (SHA256 sha256 = SHA256.Create()) {
        byte[] hashBytes = sha256.ComputeHash(inputBytes);
        string base64Hash = Convert.ToBase64String(hashBytes);
        return base64Hash;
    }
}

    3. ReactJs / Node.js

    import CryptoJS from 'crypto-js';

function computeSha256HashBase64(inputString) {
    const hash = CryptoJS.SHA256(inputString);
    const base64Hash = CryptoJS.enc.Base64.stringify(hash);
    return base64Hash;
}
