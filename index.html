Tích hợp nhanh

Tích hợp đơn giản, nhanh chóng với bộ API đầy đủ: khởi tạo thanh toán, kiểm tra trạng thái giao dịch và hoàn tiền.

Bảo mật cao

Tuân thủ tiêu chuẩn PCI-DSS. Mã hóa SSL/TLS. Xác thực chữ ký RSA-SHA256 cho mọi giao dịch.

Hỗ trợ đầy đủ: thẻ nội địa (ATM/Napas), thẻ quốc tế (Visa, Mastercard, JCB), chuyển khoản ngân hàng, QR Pay và trả góp — tất cả trong một cổng duy nhất.

II. MÔ HÌNH TRUYỀN THÔNG

  • Pay2Pay sử dụng tiêu chuẩn kết nối HTTPS/TLS1.2.
  • Mọi yêu cầu được gửi từ phía người bán đều phải được xác thực bằng giải pháp JSON Web Token.
  • Pay2Pay cung cấp API theo tiêu chuẩn Restful Webservice, truyền và nhận dữ liệu ở định dạng JSON.
  • Để đảm bảo việc truyền và nhận dữ liệu giữa hai bên được an toàn và xác thực, tất cả dữ liệu sẽ được mã hóa và ký điện tử.

III. XÁC THỰC MÃ THÔNG BÁO WEB JSON & CHỮ KÝ SỐ

Tất cả các yêu cầu từ người bán gửi đến hệ thống Pay2Pay đều cần được ủy quyền để đảm bảo an ninh.

III.2. CHỮ KÝ ĐIỆN TỬ (RSA-2048)

  • Người bán tạo cặp khóa RSA-2048 (khóa riêng tư và khóa công khai).
  • Khóa riêng tư dành cho người bán để tạo chữ ký. Khóa công khai gửi cho Pay2Pay để xác minh.
  • Cách tạo chữ ký:
    Bước 1: Lọc và sắp xếp các tham số header (bắt đầu bằng p-) theo bảng chữ cái và nối lại.
    Bước 2: Kết hợp với phần thân (body) yêu cầu.
    Bước 3: Chữ ký = SHA256withRSA(Chuỗi cần ký)

VIII. CODE SAMPLE

1. PHP

function computeSha256HashBase64( $inputString ) {
    // Tính toán mã băm SHA-256 của chuỗi đầu vào
    $hash = hash( 'sha256', $inputString, true );
    // Mã hóa giá trị băm thu được dưới dạng Base64
    $base64Hash = base64_encode( $hash );
    return $base64Hash;
}

2. C#

public static string ComputeSha256HashBase64(string inputString) {
    byte[] inputBytes = Encoding.UTF8.GetBytes(inputString);
    using (SHA256 sha256 = SHA256.Create()) {
        byte[] hashBytes = sha256.ComputeHash(inputBytes);
        string base64Hash = Convert.ToBase64String(hashBytes);
        return base64Hash;
    }
}

3. ReactJs / Node.js

import CryptoJS from 'crypto-js';

function computeSha256HashBase64(inputString) {
    const hash = CryptoJS.SHA256(inputString);
    const base64Hash = CryptoJS.enc.Base64.stringify(hash);
    return base64Hash;
}
